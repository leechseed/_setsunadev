# Proposal · S7 scenarios (trial)

## Why
The SOP rows grew into walls of appended text, and nothing checks a rule. This trial gives every §7 rule a WHEN/THEN scenario, so the audit script can flag rules without one.

## What changes
- §7 is reformatted: one `### 7.N` block per rule, a plain rule sentence, WHEN/THEN scenarios, and a `<sub>` line for date and source.
- Rules are reordered by number (the old file had 9, 10 before 8).
- No rule's meaning changes. Rule numbers stay, so "SOP §7 rule 10" citations still hold.
