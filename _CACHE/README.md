# _CACHE — the Ready Rack

Rounds staged for immediate use. One session note per working session: `YYYY-MM-DD[-n].session.md` — what moved, what was ruled, what is mid-flight.

**Flush protocol (SOP.md §3):** on every sit rep, the notes here are read (sit rep Block 0 — "last session"), then **moved** to `_LOG/`. This folder returns to empty. An empty Rack means the handoff completed.

This README never flushes.
