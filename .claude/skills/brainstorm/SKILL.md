# Brainstorm

Standing rulings that apply:
- **Riff topics, not scripts (10/4):** hold topic bullets to riff on; scripted question lists lock Chief in.
- **Default public, no gating questions (9/10):** when the default is obvious, make the call and mark it provisional. Do not ask.
- **Go recommended (10/12):** a plain yes takes every rec on the last offer. End offers with "say go".

## Steps

1. **Check what is known.** If the request already holds what matters, say so and offer to skip the questions.
2. **Ask one question per message.** Open question first; a short menu only when Chief is stuck. If he says "just guess", propose something concrete.
3. **Offer alternatives with a rec.** Two or three options, each one line, one marked as the rec and why.
4. **Play back as you go.** After each settled part, restate it in a few bullets, mark guesses as guesses, ask what is wrong.
5. **Stop on "lock it".** Write the design as a short brief: goal · what is in · what is out · decisions made (with provisional marks) · open calls with a rec each. Save where Chief names, or reply with it if none named.

Nothing gets built during the riff. Reading files is fine.
