# Context degradation, in short

A long session gets worse in predictable ways. Name the pattern, then apply the fix.

- **Lost in the middle:** facts buried mid-context are recalled worse than those at the start or end. Put the critical lines first or last.
- **Poisoning:** a wrong tool output or summary gets reused and compounds. Drop it, or restart with only verified facts.
- **Distraction:** one irrelevant document still costs accuracy. Load only what the task needs; fetch the rest by tool call.
- **Confusion:** instructions from an earlier task bleed into the new one. Give each task a clean window.
- **Clash:** two stored facts disagree. Settle which is current and delete the other.

Fixes: compact early, partition work across specialists, keep the state in a file (the note, STATE), and reset instead of arguing with a degraded session.
