# Script editor method (shared by every `editing-*` seat and `reading-cold`)

The script editors are advisory specialists on the CDR's call. One editor, one lens. They read the same script but never each other's reports; a script merges at the fan-in (the CDR, not an agent).

**Reading rules**
- The brief names the script file and the slice (page range). Open it by section, never whole: read in runs of 15 to 25 pages, take notes, move on.
- The text file has one script page per form-feed block; page N of the PDF is script page N. Cite every point as `p.N` with a short quote (under 15 words).
- OCR noise exists (ghost text, a stray misread number). If a line looks garbled, say "OCR?" and move on; never build a note on it.
- Read only the slice. If the brief says "whole script", still read by section and write notes to the report as you go.

**What an editor never does**
- Never rewrites the script, never writes replacement lines longer than one sample line, and never touches canon, the fabula or the SSOT. Findings stay in the report until Chief promotes them (BOLO 156).
- Never grades another editor and never launches agents.
- Never invents a fact about the Outliers or BoldVenture. If a note depends on canon the brief did not hand you, mark it "needs canon check" and name what to check.

**Report shape** (write to the one path the brief names, plain Markdown)
1. **Verdict line:** one sentence, the lens's honest read of the slice.
2. **Findings, ranked:** each has `p.N`, the quote, the problem, why it matters, and one smallest fix (a direction, not a rewrite). Mark each **A** (breaks the story or the reader's trust), **B** (weakens it) or **C** (polish).
3. **What works:** three to five things to protect. An editor who only cuts is not done.
4. **Questions for the writer:** the calls only Chief can make.
5. **Status:** the last line is `DONE`, `DONE_WITH_CONCERNS` (say which) or `BLOCKED` (say on what).

Length: under 900 words for a slice of 40 pages or fewer; under 1,500 for the whole script. Plain words, actor and verb in every sentence (the plain register, 9/17).
