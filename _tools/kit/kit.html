15 skills · 43 agents · 5 hooks · 1 workflow 29 adopted from GitHub

Everything the Command runs. A skill is a procedure you fire with a proword. An agent is a specialist the main session sends on one job. A hook runs by itself on an event. A workflow is a script that runs a whole formation. Each card says what it does, how you fire it, where it came from, and which BOLOs name it (green = a live BOLO). Repos it draws on: affaan-m/ECC, obra/superpowers, taste-skill, tjboudreaux/cc-thinking-skills. Built Oct 13, 10:03 AM.
