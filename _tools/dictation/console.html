Wire

      
BUILT 9/17. The wire is an MCP server, wire.py, spawned
        by the VS Code session from .mcp.json at the repo root. It exposes
        brain.py's seven tools — blocked · bolo · pmcs · effort · box · time · help —
        unchanged, each returning the spoken form. No model behind it (RULED 9/17: the router
        stays), no key, no standing cost. Prove it any time: python wire_probe.py.
        The session sees the tools after a reload.
