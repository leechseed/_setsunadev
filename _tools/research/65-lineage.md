# BOLO 65: the lineage question (first step only)

Status: research note, 2026-10-12. Nothing in the Command was renamed.

## The question
The Command's spine is Marine (MCDP, SOP, BOLO, FRAGO, Oscar Mike) plus NASA (CDR, MS, PS, go for launch, the poll). Chief asked if NASA is dated. Should the Command borrow from Space Force, Air Force or SpaceX?

## What each lineage offers

**NASA (stay).** NASA names roles by job. The Commander owns the vehicle, crew and mission. The Mission Specialist runs systems and payload work. The Payload Specialist is a guest expert for one payload. That is how the Command uses CDR, MS and PS. Source: [Astronaut ranks and positions](https://en.wikipedia.org/wiki/Astronaut_ranks_and_positions).

**SpaceX / Crew Dragon (already NASA).** SpaceX publishes no operating doctrine. Its crews use Commander, Pilot and Mission Specialist. Those are NASA's words. Source: [Crew-3 profile](https://www.eoportal.org/other-space-activities/crew-3). One useful point: the Dragon MS watches "timelines, telemetry and consumables." That fits RANGE's reviewer job.

**Space Force.** The Space Capstone Publication, *Spacepower*, is public (released 2020-08-10). It explains why, how, who and what the force values. It is a theory book, not a procedure book. Sources: [Space Capstone Publication](https://media.defense.gov/2022/Jan/19/2002924108/-1/-1/0/SPACE%2520CAPSTONE%2520PUBLICATION%2520(10%2520AUG%25202020%2520-%2520AS%2520RELEASED%2520BY%2520CSO).PDF) and [DTIC copy](https://apps.dtic.mil/sti/pdfs/AD1129735.pdf). Not verified this pass: the names of the later SDP series.

**Air Force.** The AFDP series is public. It is a likely source for a tiers idea (capstone, then keystone, then operational). I did not read it this pass.

## What each would give the Command
- Vocabulary: NASA already covers it (crew grades, the poll, go for launch). Space Force and Air Force add rank words the Command does not need.
- Procedure: the useful borrow is the tier idea. One capstone page (why), keystone pages (how), then checklists. The Command already has this shape: CLAUDE.md, SOP, skills.
- Citable text: only NASA, USSF and USAF are public. SpaceX gives nothing to cite.

## Rec
Stay NASA for names. Borrow one structure from USSF/USAF: label each doctrine page capstone, keystone or operational. Change no words.
