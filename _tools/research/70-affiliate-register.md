# BOLO 70: the affiliate register (first step only)

Status: research note, 2026-10-12. Pairs with BOLO 67 (folded into BOLO 95).

Limits: Wirecutter, NerdWallet, Spruce, Bon Appetit and Tom's Guide blocked my fetch or returned only titles. RTINGS returned its header. The rules below come from RTINGS, two guides on comparison pages, the Claude Code docs, and standard practice. Confidence is marked. Re-check against full pages if Chief saves copies.

## Rules
1. **Put the pick before the explanation.** Open with a short pick list by use case: "Best overall," "Best budget." Example: [RTINGS best for running](https://www.rtings.com/headphones/reviews/best/by-usage/running). High.
2. **Title with count, topic, year.** "The 6 Best X for Y of 2026." The reader knows the scope at once. Example: same RTINGS page. High.
3. **Label every item by who it is for.** Name the use, not the brand. Example: RTINGS use-case menu. High.
4. **State the testing line near the top.** One sentence on how many items were tested. Example: RTINGS page header. High.
5. **Put the affiliate disclosure near the top, one line.** Example: RTINGS page header. High.
6. **Put the verdict first, in a short block.** One or two sentences saying who should buy it. Example: [Texta, comparison pages](https://www.texta.ai/blog/ai-search-optimization-for-comparison-landing). Medium.
7. **Use a comparison table for about five items or fewer.** Same columns for every item, clear headers, price shown. Example: [Ninja Tables](https://ninjatables.com/comparison-table-best-practices/). Medium. The five-item cap is secondhand; unverified.
8. **Repeat the same block for each item.** Label, verdict, pros, cons, price, in the same order. Example: [Ninja Tables](https://ninjatables.com/comparison-table-best-practices/). Medium.
9. **Define a hard term in the sentence where it first appears.** Pattern: "X, which means Y." Example: [How Claude Code works](https://code.claude.com/docs/en/how-claude-code-works). High (BOLO 67 measured it).
10. **Open sentences on the reader or the product doing a verb.** "You get...", "It holds...". Example: same Claude Code page. High.
11. **Give each number its meaning.** "Lasts 10 hours, enough for a work day." Example: same Claude Code page. Medium.
12. **End with a short "how to choose," then FAQ.** Pick by need, not by feature list. Example: [Texta](https://www.texta.ai/blog/ai-search-optimization-for-comparison-landing). Low-medium.
13. **Flag claims you cannot check.** Example: the Ninja Tables page cites a vendor stat I could not verify. Medium.

## For the Command
Rules 1, 3, 6, 8, 9, 10 map onto the plain register and the sit rep. Rules 2, 4, 5, 7, 12 fit the hot sheet and the buying pages.
