World View

09 · the view

The world view compiles the catalog and the setting place headers into one read-only page. It is a view: it stores nothing and has no input fields.

To change an entry, open its file (the name links to it) and edit it there. Then rerun python _tools/worldview/build.py and republish.

Second build (09 to 1.0, 9/29): it reads the catalog, setting (03) places, character (02) nodes, plot (04) fabula events, tracking (08) story points and the trope register. Script tests run on every build; the reader tests are judged by reading and folded in.
