# Osiris (simplifaisoul/osiris)

Source for every claim below: https://github.com/simplifaisoul/osiris (README). Fetched 2026-10-17. Nothing was installed or run.

## What it is
- Osiris is an open-source, real-time global intelligence dashboard. The repo calls it "A Palantir Alternative". https://github.com/simplifaisoul/osiris
- License is MIT. Live demo at osirisai.live. https://github.com/simplifaisoul/osiris
- Stack: Next.js 16, TypeScript, MapLibre GL (WebGL map). https://github.com/simplifaisoul/osiris

## What it does
- Sixteen toggleable map layers with live entity counts. https://github.com/simplifaisoul/osiris
- Data: flights (OpenSky), 17,000+ public CCTV cameras, USGS quakes, NASA fire hotspots, 23 live news streams, NOAA space weather, satellites (N2YO), CVEs (NVD). https://github.com/simplifaisoul/osiris
- Crypto wallet tracing (BTC, ETH) checked against the OFAC sanctions list. https://github.com/simplifaisoul/osiris
- Geoparsed posts from public Telegram channels. https://github.com/simplifaisoul/osiris
- A RECON panel: port scan, DNS, WHOIS, SSL, vulnerability lookup. https://github.com/simplifaisoul/osiris
- "OI Assist": press O, type or speak, and the map flies and switches layers. https://github.com/simplifaisoul/osiris
- "OI Forecast": runs simulated "worlds" of actors, then writes a forecast with source-linked claims. Needs the user's own model API key. https://github.com/simplifaisoul/osiris
- Draw an area on the map; see every camera inside it; export GeoJSON. https://github.com/simplifaisoul/osiris

## Look and feel
- Full-screen dark "Night" map with HUD-style panels, 3D terrain, a day/night cycle. https://github.com/simplifaisoul/osiris
- Cyan markers for Telegram and AI results. Red for conflict zones. A red "SANCTIONED" badge on flagged wallets. https://github.com/simplifaisoul/osiris
- Three README screenshots: Taipei camera feeds, Seoul in 3D terrain, a drawn-area camera search. https://github.com/simplifaisoul/osiris
- Single-key shortcuts (F flights, E quakes, S satellites, D day/night, Esc closes). https://github.com/simplifaisoul/osiris

## Providence lens
1. **One map, every feed.** Providence sells fusion, not one sensor. Osiris stacks flights, cameras, news and cyber on one globe.
2. **Camera mesh.** Osiris links 17,000+ public cameras. Providence could own the city grid and show each feed on click.
3. **Draw-an-area query.** A citizen-zone lasso that lists every camera and person inside. Osiris does this with a drawn region.
4. **Conversational operator.** A spoken command that flies the map. Osiris's OI Assist works this way. The AI "ruler" in the canon entry could speak through it.
5. **Simulated worlds.** Osiris runs parallel actor simulations before it forecasts. This fits the "Predicted" step of the Safety gauge.
6. **Sanctions badge.** A red flag attached to a person or wallet on sight. Providence's "Watched" step in a single icon.
7. **Telegram-style scraping of public chatter.** Geoparsed posts become map dots. Providence reads what citizens say aloud.
8. **Counts everywhere.** Every layer shows a live number. A nation that counts everything.

**On screen:** a dark globe, thin cyan and red points, small HUD panels, and a status number that ticks on every layer. It reads calm and clinical, not cinematic. That is the horror: the surveillance looks like a weather app.

## Risks
- Osiris is an OSINT and surveillance tool with port scanning, WHOIS and wallet tracing. Reference only. The Command does not run it on real people or real targets. Not installed.
- The README has no terms-of-use beyond MIT.
- The project makes its own performance and key-privacy claims. We did not verify them.

## Verdict
**REFERENCE (story only).** It shows what a fusion dashboard looks like and feels like. It adds nothing the Command should run. Use it for Providence's interface, vocabulary and visual language only.
