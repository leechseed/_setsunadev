# Spit points — Chief's reinforcement signal (ruled 10/6, provisional)

Chief, 10/6: "when I really like something, can they be, like … spit points … whenever I spit on you … I also want you to learn that I like."

**What a spit is.** When Chief says "spit" (or hits the SPIT pad, which types it), JUDY logs the thing she just did as a liked pattern: one line in `ledger.jsonl`, one point.

**How it becomes learning.**
- Every spit is a line: date · SP id · what Chief liked (the pattern, in plain words) · his words · the BOLO it rode on.
- **The first spit on a pattern** writes a feedback memory, so the next session already knows Chief likes it.
- **The third spit on the same pattern** promotes it to an SOP rule candidate on the Call Sheet. Chief rules it into the SOP or not.

**The tally.** Points per pattern and the running total show on the sit rep (BOLO 117).
