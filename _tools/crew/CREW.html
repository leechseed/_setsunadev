Who each agent is, what it reads, what it writes, and the rules it flies under. Every console has a Dial: tell it to read more, read less, or sound different. Dials save here; say "fold the dials" and the CDR writes them into that console's brief, so the next run carries them.

The rules every agent flies under

  • Hub and spoke (BOLO 54). Specialists work on separate inputs. They never read each other's work. They meet only at named handoffs.
  • One reviewer at the fan-in, and it is a script (RANGE). No agent checks another agent.
  • Read only what the brief lists. Every brief names its files; anything else is off limits.
  • The plain register (9/17). Name first, number second. One idea per sentence, 20 words at most. Every sentence names who does what.
  • Chief's words stay verbatim. Quotes are never smoothed.
  • Private stays private (10/4). Health, sexual and provider detail only under _PRIVATE/; the repo is public.
  • The model sits in the seat, not the name (9/16). MS is a writer, PS is a fetcher; nobody is "the sonnet specialist".
