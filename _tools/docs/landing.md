# The Command reference site: start here

**Who it's for:** Chief, before phase 2, reading the whole stack · **What it does:** explains how the pieces fit, so every other page makes sense · **Type:** concept

Read this page front to back. It takes a few minutes. Every other page is a reference page you skim.

## How the stack fits

**The base (00).** The base holds what every other system stands on. It defines how the Command decides what is true. It sets the number system, the variable registry, and the module rules. Nothing above it works without it.

**The storytelling systems (01–08).** These are the method. Each system covers one part of a story: framework, character, setting, plot, style, theme, tracking, and world. They describe how to build a story. They do not hold any one story.

**The Touchstones (built last, read first).** The Touchstones are the rules the story guides itself by. Chief ruled they come last, after the machinery exists. They also come first for a reader. They are the easy way into the system. Start there.

**The fabula (phase 2, eras 1–5).** The fabula is the world's own timeline, shared by every story. Phase 2 fills it, era by era. The eras run from Skeeter Creek through DCUS and LAKAD to ASTRO7EX and beyond. The fabula doc exists today at version 0.2.0. It is not filled.

**The pilot (gated, BOLO 100).** The pilot is the first piece of story writing. Chief gated it. Every system must finish first, and the full fabula must exist from beginning to end. No pilot writing starts before that.

## The systems, one line each

- **00 Base (epistemology and shared tools).** The truth doc "defines frameworks for determining truth across empirical, logical, intuitive, consensual, and pragmatic methods" (1.0.1). The base 60 number system is the source of all integers (1.0.1). The variable registry indexes every character variable (1.2.1). The module architecture and registry cover plug-in capability (1.0.1 and 1.1.0). The Bold Venture design system is a Command-wide tool, not part of the storytelling stack (2.0.1).
- **01 Narrative frameworks.** The story spine is "the canonical tree of what makes a story" (1.0.1). Around it sit the scale ladder, the texture layer, the medium grammars, the genre system, and Modern Poetics. The register of Touchstones lives here (1.0.0).
- **02 Character systems.** The vertical slice is the LEECHSEED character system (3.3.3). Dramatica integration (1.2.2), astrology (1.1.0), and character state (1.3.0) feed it.
- **03 Setting systems.** The setting system is "character-grade place": a taxonomy, a 12-layer setting slice, and the scene card (1.10.1). Setting state tracks place change over time (1.2.0).
- **04 Plot systems.** The plot system is the syuzhet, the told order of events (1.3.1). The fabula is the world-time layer beneath it (0.2.0). The trope graph holds the rails the plot rides (1.0.0).
- **05 Worldbuilding systems.** The worldbuilding system defines a world, its coherence tests, and the catalog of shared things no other system holds (1.1.1).
- **06 Theme systems.** The theme system is "the argument's value layer": what the story argues, in one sentence (1.3.1).
- **07 Style guides.** Prose style says how the stories read on the page (1.3.1). Documents style says how the Command writes (1.5.0). Pages style says how artifacts look (1.0.0).
- **08 Tracking systems.** The tracking system is the shared time grid and record model under character state, setting overlays, and world time (1.1.0).
- **09 Operations.** These are Command operations. They sit outside the storytelling stack. Chief, 10/4: "just from the storytelling aspect." The project flow defines how a project runs (0.1.1). The development standard defines the build loop inside a session (0.1.2). Several 05 docs have no purpose line yet.

## The stories

The stories are instances of the method. They stay apart from it. OXO is the series called The Outliers. EVIL CHECK is a second story in the same universe. Each story fills the systems with its own characters, places, and events. That fill work is phase 2. Until then, the story pages show what exists, not what is finished. The story registry in 01 lists every story in the universe.

## How to read this site

Reference pages are for skimming. Look up what you need, then leave. Do not read them front to back.

Start at the Touchstones. They are the front door. Then follow the side panel into whichever system a Touchstone points to.

Mark each page read as you finish it. The marks show what is left before phase 2.
