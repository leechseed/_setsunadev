## TWO DIFFERENT TAG SYSTEMS

### 1. FRONTMATTER TAGS (Properties)

**Location**: Inside YAML frontmatter
**Purpose**: Metadata, categorization, filtering in Bases
**Format**: `tags: [tag1, tag2, tag3]`

**Example**:
```yaml
---
type: ssot_methodology
tags: [astrology, character-systems, dramatica]
---
```

**Used by**:
- Obsidian Bases for filtering
- Search and queries
- Metadata organization

---

### 2. INLINE TAGS (Promotion)

**Location**: In document body
**Purpose**: Trigger Auto Note Mover, mark content for promotion
**Format**: `#canon-ready` `#ssot-candidate` `#auth-candidate`

**Example**:
```markdown
## Section Title #ssot-candidate

This content needs promotion to Canon.
```

**Used by**:
- Auto Note Mover plugin (auto-staging)
- Promotion Queue Base (visualization)
- Workflow automation

---

## WHEN TO USE EACH

### Use Frontmatter Tags When:
- Organizing Canon documents
- Creating Base filters
- Adding metadata categories
- Permanent classification

### Use Inline Tags When:
- Working in Goon Room sessions
- Marking content for promotion
- Triggering auto-staging
- Temporary workflow states

---
