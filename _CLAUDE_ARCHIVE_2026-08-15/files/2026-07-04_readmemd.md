# Security Agent (Claude Code)

A ready-to-run Claude Code project preloaded with a curated set of **defensive**
cybersecurity skills — DFIR, threat hunting, SOC/log analysis, malware analysis, cloud
audit, incident response, and vulnerability triage.

Skills are sourced from [`mukul975/Anthropic-Cybersecurity-Skills`](https://github.com/mukul975/Anthropic-Cybersecurity-Skills)
(Apache-2.0, **community project — not affiliated with Anthropic**).

## Quick start

```bash
bash setup.sh     # installs the 27-skill curated starter set into .claude/skills/
claude            # open Claude Code in this directory
```

Then, inside Claude Code:

```
/skills           # confirm the security skills loaded
```

Now just ask, e.g.:

> "Use analyzing-memory-forensics-with-lime-and-volatility to walk me through triaging
> this memory capture."

## Add more skills

```bash
bash setup.sh --list                       # all ~45 subdomains + skill counts
bash setup.sh --domain digital-forensics   # add a whole subdomain (41 skills)
bash setup.sh --domain threat-hunting      # (58 skills)
bash setup.sh --all                        # everything (817 — heavy; read the note below)
```

Re-running is safe; it overwrites matching skill folders and skips the rest.

## Why not just install all 817?

817 skills is roughly **20k+ tokens of skill metadata** competing for attention on every
task, and it bleeds security content into unrelated work. This scaffold installs
**project-scoped** (`.claude/skills/`, not `~/.claude/skills/`) and starts with a focused set.
Add subdomains as you actually need them. If you want a permanent, always-on security agent
instead, copy the folders into `~/.claude/skills/`.

## Heads-up before you rely on it

- **Not an Anthropic project.** The source repo borrows the "Anthropic" name; it's an
  individual's community project. The framework mappings (MITRE ATT&CK, NIST CSF 2.0, D3FEND,
  ATLAS) are real and useful.
- **The skills contain real, runnable Python** (`scripts/agent.py`, ~150–260 lines each). Some
  domains in the source repo (red-teaming, pentest, credential-access) are genuinely offensive
  tooling. The starter set here is defensive, but **review any script before letting the agent
  run it**, and keep Claude Code's permission prompts on — don't use
  `--dangerously-skip-permissions`.
- **Stay in scope.** Only analyze systems, images, logs, and samples you're authorized to touch.
