# _ARCHIVE — the ancients

**Archaeology only. Nothing in here is live.** Folders land here whole, exactly as they stood on the day they were archived; anything worth keeping alive was **promoted out first** to its real home, and `INDEX.md` says where. Git history carries every file regardless.

Rules:

1. **Nothing is deleted.** Archiving is a move, never a purge.
2. **Promote, then park.** If a folder has live value, the live piece gets a canonical home *before* the shell comes here.
3. **One row per folder in `INDEX.md`:** archived date, what it was, last real touch, what was promoted out and to where.
4. **No new work in here.** If something in the archive wakes up, it gets a fresh home; the archived copy stays as the snapshot.

The `X_` / `XX_` filename-prefix convention (README: "archived/deprecated, don't touch") is superseded by this folder as of 2026-09-03.
