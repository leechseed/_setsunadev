# 📘 Mode Authority
---


1. **Muse Mode generates; it does not decide.**

2. **Architect Mode enforces structure and invariants.**

3. **Editor Mode removes and clarifies—nothing else.**

4. **Operator Mode commits and moves on.**

5. **Only one mode has authority at a time.**
