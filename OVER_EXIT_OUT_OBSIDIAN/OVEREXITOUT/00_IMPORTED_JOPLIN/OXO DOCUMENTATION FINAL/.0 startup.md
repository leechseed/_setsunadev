```markdown
# 📘 AI Docs Agent — Operating Procedure

**System Name:** ai-docs-agent  
**Purpose:** Local retrieval agent for querying your Joplin Markdown canon and copying grounded context to clipboard for use in GPT, documents, or code.

```

C:\Users\U01_LEECHSEED\Desktop\ai-docs-agent

````
## 🧱 Required Files (Baseline Integrity Check)

Ensure the following exist before use:

- `ask_docs.py` — query + clipboard tool
- `index_docs.py` — index builder
- `config.json` — source configuration
- `docs.index` — FAISS vector index
- `docs.jsonl` — chunk metadata
- `build_meta.json` — build summary
- `.venv\` — Python virtual environment

If any are missing, the system will not function correctly.

## 🟢 BOOT PROCEDURE (Start the Agent)

### Step 1 — Open PowerShell
- Press **Windows key**
- Type **PowerShell**
- Open it

### Step 2 — Navigate to the project folder
```powershell
cd "C:\Users\U01_LEECHSEED\Desktop\ai-docs-agent"
````

### Step 3 — Activate the virtual environment

```powershell
.\.venv\Scripts\activate
```

**Verification:**
Your prompt should now start with:

```
(.venv)
```

### Step 4 — Launch the query tool

```powershell
python ask_docs.py
```

**Expected Output:**

```
Ready. Type a question.
```

The agent is now live.

## 🧠 USE PROCEDURE (Day-to-Day Operation)

### Step 1 — Ask a query

At the `ask>` prompt, type a query such as:

* `Narrative invariants`
* `Layer 5`
* `Transmission moves`
* `Truth does not interrupt enforcement`

Press **Enter**.

---

### Step 2 — Clipboard behavior (automatic)

* Results may print to the terminal
* Results are **automatically copied to clipboard**
* Confirmation message:

  ```
  [copied to clipboard]
  ```

---

### Step 3 — Paste anywhere

Press **Ctrl + V** into:

* ChatGPT
* Joplin
* VS Code
* Markdown documents
* Google Docs

No scrolling or manual selection required.

---

## ⚙️ Runtime Commands (While the Agent Is Running)

| Command         | Function                             |
| --------------- | ------------------------------------ |
| `:quit`         | Exit the program                     |
| `:k=10`         | Set number of results                |
| `:min=0.25`     | Raise relevance threshold            |
| `:copyonly on`  | Suppress terminal output, still copy |
| `:copyonly off` | Restore terminal output              |

---

## 🔄 UPDATE PROCEDURE (Rebuild the Index)

Run this when you’ve added or edited a significant number of notes.

### Step 1 — Exit the query tool

Inside the agent:

```
:quit
```

### Step 2 — Rebuild the index

With the virtual environment still active:

```powershell
python index_docs.py
```

Wait until indexing completes.

### Step 3 — Restart the query tool

```powershell
python ask_docs.py
```

---

## 🔴 SHUTDOWN PROCEDURE (Turn It Off)

### Step 1 — Exit the query tool

```
:quit
```

### Step 2 — Deactivate the virtual environment

```powershell
deactivate
```

### Step 3 — Close PowerShell

Nothing remains running.
