## THE DOCUMENTATION RULES — THE CORE (BOLO 95)

- **What it is:** the core of 06.2. Folded in 2026-10-04 (BOLO 92). Chief locked each rule by teach-back between 2026-09-30 and 2026-10-03.
- **Record:** `_tools/bolostatus/work/95/DOC-SOP.md` holds the readbacks and sources.
- **Precedence:** where 06.2a or 06.2b disagree, this section wins.
- **Applied so far (2026-10-04):** the SOI (three passes, 46 entries rewritten), the sit rep page, and the DOPE SHEETs (header, writer briefs, a long-sentence check in the reviewer script).

**1 · One page, one job**

| # | Rule | Locked |
|---|---|---|
| 1.1 | Every document does one job. A page that does two becomes two pages. The job is doing (reader skims for a step) or understanding (reader reads through). | 2026-09-30 |
| 1.2 | Four types: tutorial (a lesson, learned by doing), how-to (a recipe for one task), reference (facts looked up and left), concept (the why, read front to back). Concept is the one understanding page. | 2026-10-03 |
| 1.3 | Writing order: concept, reference, how-to, tutorial. Readers meet them in the opposite order. | 2026-10-03 |

**2 · The page header**

| # | Rule | Locked |
|---|---|---|
| 2.1 | Every page names who it is for (reader and situation), what it does (one job, one line), and which type it is. | 2026-10-03 |
| 2.2 | Under those: owner (who decides), state (draft, ruled, retired), reviewed (date last checked against the truth). | 2026-10-03 |
| 2.3 | The 2.1 three sit in one thin strip up top. The 2.2 three sit one click away: behind a button on a page, in the front matter of a markdown file. | 2026-10-03 |

**3 · The words**

| # | Rule | Locked |
|---|---|---|
| 3.1 | One word for each thing, only that word. Define it on first appearance. | 2026-10-03 |
| 3.2 | One idea per sentence. Every sentence names who does what. Read aloud; 20 words is the scripts' check. | 2026-10-03 |
| 3.3 | Docs stay plain. The rich description goes in one marked section, "The long read," at the foot of a concept page. Story prose follows 06.1. | 2026-10-03 |
| 3.4 | Review in passes: facts, words, out loud. One sentence per line. Five word-pass questions: who acts, is the verb active, can any word go, can a literal reader take the wrong branch, is the key word at the end. A script runs the first two. A ruled page is never edited quietly. | 2026-10-03 |
| 3.5 | Doing pages use practical voice. Concept pages use classic voice. Session notes and logs stay out of classic voice. | 2026-10-04 |
| 3.6 | Order of ideas: headings state ideas; each list passes the plural-noun test and has a named order (argument, time, structure, importance); the opening holds only what the reader accepts; a hinge sentence joins sections. | 2026-10-04 |

**4 · The extra page types**

| # | Rule | Locked |
|---|---|---|
| 4.1 | Troubleshooting: starts from what the reader sees. One entry per problem: symptom, cause, fix. The heading is the symptom in the reader's words. | 2026-10-03 |
| 4.2 | Glossary: one entry per term, alphabetical. Each entry is the term, a one-line plain meaning, and a link to where it is used. An old name points to the current one. | 2026-10-03 |
| 4.3 | Decision record: one decision per page, dated, with who ruled it. Three parts: decided, why, gave up. Never edited after ruling; a new decision gets a new record that points back. | 2026-10-03 |

SOP §7 is the authority for replies. This table is a locator, not a replacement.

| # | Rule, in one line | Citation |

| 4 | Parallel items go in bullets or tables, never buried in prose. | coded 2026-08-21 |
