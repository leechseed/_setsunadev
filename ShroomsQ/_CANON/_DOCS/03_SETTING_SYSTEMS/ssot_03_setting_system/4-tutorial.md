# The setting system: tutorial

You will read the Delta Coast Ultra School (DCUS) slice as the source documents it, then find its flags. Keep the [reference](2-reference.md) open.

1. **Read the header.** DCUS is a site (campus). Its parent is the Middle Bands, Delta Coast, tri-state Spiral. It has these names: DCUS, the Ultra School, Red Hills Academy, Skeeter Creek and Inner Spiral Academy.
2. **Start thin.** Only the header and S12 are needed. Ask: which layer does the story press on first? S5 SCAR, the rename lattice.
3. **Read S5.** The lattice runs Skeeter Creek, then Red Hills, then DCUS. The erasure happened twice. Legacy students who say "Red Hills" commit a small legibility violation.
4. **Check the S5 fields.** The `record` has five entries and the instance leaves them parked. Predict the flag: RUIN_INERT fires if an entry has no builder or no fall.
5. **Read S9.** The promise is meritocracy. It is the premise Tori must stop believing (Growth: Stop). The wound (S5) and the promise (S9) link, so WOUND_PROMISE_FUSED applies if one rupture feeds both.
6. **Read S12.** The `storyform_id` is `oxo_primary_v1`. The place embodies the OS Domain, Situation and The Past. A place with S12 filled is load-bearing, so LOAD_BEARING is active.
7. **Pin one scene.** Open a SCENE CARD. Set `setting` to `DCUS.campus.hall3 @ state M2`. Pick function modes Pressure and Mood. Add three sensorium details, the `governing detail` first.
8. **Close the card.** Fill the value turn, the commandments and the exit state. The exit state is what is now true that was not.
9. **Check your work.** You used one card and three layers. You did not fill all twelve. That is the fill rule working.

Next, try the [how-to](3-how-to.md) task "Build a FACTION / NATION CARD" for the Sync Cult. The source holds that card until the cult has its own canon node, so you will mark the gaps.
