# Setting synthesis: how-to

## Check how deep a layer is before you write it

1. Open Part One of the [reference](2-reference.md).
2. Find the layer (S1 to S12).
3. Read its depth call. Method depth and instance depth are separate.
4. If the method is deep but the instance is thin, write the instance only when the story visits the place.

## Fold a new distill into the setting slice

1. Read the distill's `feeds:` block.
2. Note each S-layer it feeds and the strength: primary, supporting or contextual.
3. Sort the distill into the Part One register under those layers.
4. Check Part Two for a recurring method it repeats, and cite it there.
5. Record any proposed system change as a numbered item in Part Three, with its reason and a recommendation.

## Propose a change to the setting system

1. Write the change as one numbered item with its reason.
2. Cite every source that independently supports it.
3. State a recommendation: yes, no or bench.
4. Wait for Chief to rule. Do not edit the system first.
5. After the ruling, apply the change in ssot_03_setting_system and write the ruling and version inline.

## Resolve a contradiction between sources

1. List the sources on each side in Part Five.
2. Check whether the two sides print different forms of the same rule, as the timeline case does.
3. If they truly conflict, pick the lean and name the reason.
4. Commit to one direction for the instance.

## Close a parked DCUS application item

1. Find the item in Part Four.
2. Apply it in the DCUS instance of ssot_03_setting_system.
3. Mark the item done and cite the version that carries it.

## Avoid over-filling the slice

1. Before you fill a thin layer, ask whether a scene visits it.
2. If no scene does, leave it thin. The wave does not mandate S1 to S11 completeness.
