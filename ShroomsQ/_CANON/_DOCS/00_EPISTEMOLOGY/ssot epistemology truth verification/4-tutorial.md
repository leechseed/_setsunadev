# Truth verification: check Victoria Midnight's change

You will check one claim with four frameworks. The claim comes from the source's Example 2. By the end you will have a verdict.

**The claim:** Victoria Midnight changes from a merit believer to a system skeptic. Is that change valid?

## Step 1. Find the claim's row

The claim is about a character, so use the Character (02) row. Its frameworks are Coherence, Logical Reasoning and Empirical Observation. The source adds Pragmatic Theory for this example. You will use four.

## Step 2. Run the empirical check

Ask what psychological research says about belief change after traumatic events. Research the trauma psychology literature. Write down what you find.

> **OPEN:** the source names no specific studies for this check.

## Step 3. Run the logical check

Build a syllogism from the source's premises.

- Premise 1: the merit system protects the worthy.
- Premise 2: her brother dies despite merit.
- Conclusion: the merit system is false.

Check that the conclusion follows. The source's progression is brother's death plus system betrayal, which leads to skepticism.

## Step 4. Run the coherence check

Cross-reference the change against every scene of Victoria. Ask whether the change fits her established psychology throughout the narrative.

## Step 5. Run the pragmatic check

Ask whether the change produces effective dramatic tension. Assess its narrative impact.

## Step 6. Give the verdict

All four frameworks agree in the source. Its outcome is "validated through four-framework convergence". If one had failed, you would revise the change.
