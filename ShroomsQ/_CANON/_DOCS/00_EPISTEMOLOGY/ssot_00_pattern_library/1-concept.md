# Pattern library: simple cycles, stacked

## A pattern is a cycle that repeats at every scale

A pattern is a simple cycle. Small patterns stack on each other. The stack produces emergent structure. Chief, 10/4: "we'll be using simple patterns over and over again… then they're stacked on top each other to be emergent."

## The foundation has two halves

Truth asks what counts as true, and it checks. Pattern asks what shapes repeat, and it repeats. The [truth verification doc](../ssot%20epistemology%20truth%20verification/1-concept.md) is the Truth half. This doc is the Pattern half. Four existing docs already belong to it. They are the variable registry, module architecture, the base 60 number system and the scale ladder. Each reuses one form: one naming scheme, one module shape, one number base, one ladder of scales.

## The foundation sits at the bottom of a stack

Bottom up, the stack is Foundation, Fabula, Narratology, Operations. Foundation is truth and pattern. Fabula is the world that runs. Narratology is the lens, the bard's telling. Operations is the script that uses fabula and narratology to make narrative products.

## Three cycles share one loop

The research cycle belongs to Truth. Design patterns belong to the Pattern half. The development cycle belongs to Operations. Underneath, all three run one loop: try, check, adjust, repeat. Engineers call it plan, do, check, act.

## Two patterns are ruled

Pattern 1, the Command loop, is the way Chief works. Its steps are speak, capture, recon, recs, one-word ruling, build, script check, publish, log. Pattern 2, the change cycle, is want, push, cost, change. Recognizing a pattern lets the Command develop it.

## The long read

The Command loop is the SOP's four steps (recon, order, execute, consolidate) seen as a pattern. On 10/4 the loop ran about eight times. It took the ten system review pages from 1 of 10 to 10 of 10 passing. The change cycle runs at two tiers. At the fabula tier it moves the world forward. At the narratology tier it becomes the beat the bard tells. The [reference](2-reference.md) lists each pattern with its tier and scales.
