# Module registry: one list, four statuses

## The registry is the complete catalog

The registry lists every field module that attaches to the 12-Layer Character Database. A field module is a set of variables beneath a layer. The registry lists no doc modules. A doc module is a sibling document in `02_CHARACTER_SYSTEMS`.

## A module registers before it has variables

The designer registers a new module here before defining any variable. When a module moves from planned to active, its full API declaration goes here. The rule keeps the module IDs and attachment points reserved and conflict-free.

## Status says how real a module is

A module is active, absorbed, planned or conceptual. Active modules work now. Absorbed modules are closed, because the core schema now holds their fields. Planned modules have full declarations and wait for a build. Conceptual modules have a scope and a reserved ID. Their variable lists wait for the module build, phase 2.

## Absorption keeps the schema honest

The core schema absorbed the Sexuality Profile and Vocal Signature modules. The registry records where each old variable went. Some dropped with the module. A module that duplicates the core has no reason to build.

## The audit found nothing to drop

The 2026-10-04 audit checked every planned module against the slice. None dropped. Coping narrowed to two scores because the strategy moved to layer L4. The audit counts one active, two absorbed, eight planned and three conceptual modules.

## Dependencies set the build order

Two modules depend on others: Decompensation on Coping, and the LoL taxonomy on Combat. The rest are independent. The build order that gives the most independence starts with Walk, Physical Detail, Combat and Fashion. It continues with Music, Coping, Decompensation, then the LoL taxonomy.

## The long read

The Dualism module is the only one that attaches to all 12 layers. It adds a second, bipolar dimension to every layer, with a charge from -30 to +30. The range is native to base 60. Snap boundaries at ±60 mark a transcendent outlier. The [reference](2-reference.md) holds every declaration.
