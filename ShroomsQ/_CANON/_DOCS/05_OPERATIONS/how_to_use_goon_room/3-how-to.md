# The Goon Room workspace: how-to

## Start a session

1. Pick a topic.
2. Create the file `_GOON_ROOM/sessions/YYYY-MM/YYYY-MM-DD_topic.md`.
3. Name it `YYYY-MM-DD_descriptive_topic.md`, with underscores in the topic.

## Tag a passage as you work

1. Pick the tag that fits: `#canon-ready`, `#ssot-candidate`, `#auth-candidate`, `#experiment`, or `#reference`.
2. Write the tag next to the passage.
3. Keep working. The source says to tag as you go, not later.

## Run the weekly review

1. Search the Goon Room for `#canon-ready`.
2. Move each match to `_STAGED/` for review.
3. Promote reviewed items to `_CANON/` when they are ready.

> **OPEN:** the source gives no promotion criteria and no review owner.
