# The theme system: tutorial

You will rebuild OVEREXITOUT's theme in four steps. Keep the [reference](2-reference.md) open and check each answer against it.

## Step 1: write the controlling idea

1. Write the form on a blank page: *[value] happens because [cause]*.
2. Start from this: the story is about a system that trains people, scores them, then calls the score their nature.
3. Cut it to one sentence. Chief picked this one from 35 candidates on 2026-09-29:

> **Nobody has to be evil when everyone does their job.**

4. Write the mechanism line. Ask how the system does it. The ruled answer:

> *It doesn't find out who you are. It trains you, measures you, then calls the result your nature.*

5. Check your work. The sentence says what the story argues. The line says how the system does it, without repeating the what.
6. Ask the latent-theme question: what might the sentence be covering? OVEREXITOUT's answer is still parked for the phase 2 fill pass.

## Step 2: build the four rails

1. Open the storyform. Take one Issue and Counterpoint pair per throughline.
2. Turn each pair into a question. Start with the world: Interdiction versus Prediction becomes *They already know how you'll turn out. Can you prove them wrong?*
3. Do Tori's pair, Interpretation versus Senses. Write it as a question.
4. Do Anna's pair, Circumstances versus Situation.
5. Do the relationship pair, Suspicion versus Evidence.
6. Compare with the reference's rails table. Your wording may differ; Chief handpicked the plain words.
7. Read the four together. They should sum to the controlling idea. The world forecasts, Tori trusts her eyes, Anna wins as dealt, and the rivalry settles whose account survives.

## Step 3: step the value scale

1. Name the value. For OVEREXITOUT it is Freedom, because the mechanism line is about biopower.
2. Write four steps, worst to best: Freedom, Conformity, Control, and control that feels like freedom.
3. Give each step plain words. Check yours against the reference.
4. Pick a scene turn. Say which step it moves from and to.
5. Add the second gauge, Fairness, for world scenes. Its last step is "A rigged game that calls itself fair."

## Step 4: choose three motifs

1. List images in the setting that recur. Pick the uniform with its mirror, a door, and the Feed.
2. Tie each to a rail or a step. The Feed ties to debate 1 and the "You're managed, not free" step.
3. Run the two checks. Does the image recur? Do its uses converge on one meaning?
4. Confirm that the door ties to Tori's Growth, Stop. Her door is always in reach until she takes it.

## Step 5: run the handshake

1. Open the Touchstones register. Find the live Touchstone, TS 1:1 (soft).
2. For rail R2, ask how Tori's scenes can dramatize a failing container without breaking TS 1:1.
3. Read the reference's handshake table. A failing container shows the soft Touchstone working, so nothing breaks.

You now hold the full method. Next, try it on a scene card with the scene tests in the [how-to](3-how-to.md).
