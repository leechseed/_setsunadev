# Brief a small project: the BOLO 26 dictation dictionary

You will follow the source's third example, an S-size project. You finish with a five-line brief, one gate, and a HOLD that names its decider.

## Step 1. Size it

BOLO 26 is a BOLO and a tool, so it is S-size. The tailoring table gives an S a five-line brief and one gate at done. It needs no information line and no sustainment line.

## Step 2. Write the five lines

Write the lines as the source did:

- **End state:** the recognizer stops mangling the Command lexicon.
- **Intent:** fewer misreads without slowing Chief down.
- **Scope:** one tool, one dictionary.
- **Done:** a session with zero SOP §8 catches.
- **Owner:** Claude on BUILD, Chief on INSTALL or PAY.

## Step 3. Set the one gate

Place one gate at done. When a session with zero SOP §8 catches arrives, the gate fires and you run the checklist.

## Step 4. Handle the stop

The source records that the project parked in oscar-mike on the route decision. That is a HOLD. A HOLD needs three things: the blocking decision, the decider, and the date it converts to a call. Write all three on the HOLD. The source says the HOLD carried a named decider.

> **OPEN:** the source does not record the conversion date for the BOLO 26 HOLD.

## Step 5. Check yourself

Ask: could Chief tell from the brief alone what finished looks like? Here the answer is yes: zero SOP §8 catches in one session.
