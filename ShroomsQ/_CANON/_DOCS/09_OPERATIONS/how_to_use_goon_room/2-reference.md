# The Goon Room workspace: reference

The source applies to all stories (`applies_to: [all_stories]`) and has status canonical, version 1.1.0, last updated 2026-10-05.

## Daily Workflow

The workflow has four steps, run in order: start, work, tag, review.

### 1. Start a Session

The writer creates a dated file at `_GOON_ROOM/sessions/YYYY-MM/YYYY-MM-DD_topic.md`. Connects to [File Naming Convention](#file-naming-convention).

### 2. Work Freely

The writer dumps thoughts, researches, drafts, and experiments. No structure is required. Connects to [Don't Worry About](#dont-worry-about).

### 3. Tag As You Go

The writer adds one of five tags as the work goes:

| Tag | Meaning |
|---|---|
| `#canon-ready` | Ready for canon promotion |
| `#ssot-candidate` | Potential methodology update |
| `#auth-candidate` | Potential story update |
| `#experiment` | Just testing |
| `#reference` | Keep but not canon |

### 4. Weekly Review

The writer searches for `#canon-ready`, moves those passages to `_STAGED/` for review, and eventually promotes them to `_CANON/`.

Chief reviews everything in `_STAGED/`. The writer does not promote on the writer's own call. Chief rules before anything reaches `_CANON/`.

A passage qualifies for promotion when it carries `#canon-ready` and Chief rules it in. The writer checks it against the live Touchstones first. The writer then moves it to its home. A `#ssot-candidate` goes to an SSOT doc in the folder the AI instruction protocol's category-to-folder table names. Chief decides the folder for domains 03, 05, 06 and 08, so the writer parks those candidates in Chief's queue (IF catalog call 9, ruled 2026-10-05). An `#auth-candidate` goes to `_AUTHORITATIVE/`. The writer adds a version-history row naming the date and the ruling.

## File Naming Convention

The format is `YYYY-MM-DD_descriptive_topic.md`. The source's example is `2026-02-10_mars_aspects_research.md`.

## Don't Worry About

The writer does not worry about organization, cleanup, structure, or perfect formatting.

## Focus On

The writer focuses on capturing ideas, following creative flow, and tagging for later retrieval.
