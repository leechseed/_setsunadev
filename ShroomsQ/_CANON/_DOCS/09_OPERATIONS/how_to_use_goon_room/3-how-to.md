# The Goon Room workspace: how-to

## Start a session

1. Pick a topic.
2. Create the file `_GOON_ROOM/sessions/YYYY-MM/YYYY-MM-DD_topic.md`.
3. Name it `YYYY-MM-DD_descriptive_topic.md`, with underscores in the topic.

## Tag a passage as you work

1. Pick the tag that fits: `#canon-ready`, `#ssot-candidate`, `#auth-candidate`, `#experiment`, or `#reference`.
2. Write the tag next to the passage.
3. Keep working. The source says to tag as you go, not later.

## Run the weekly review

1. Search the Goon Room for `#canon-ready`.
2. Move each match to `_STAGED/` for review.
3. Wait for Chief to review everything in `_STAGED/`. The writer does not promote on the writer's own call.

## Promote a passage

1. Confirm the passage carries `#canon-ready` and that Chief has ruled it in.
2. Check the passage against the live Touchstones.
3. Move it to its home. A `#ssot-candidate` goes to an SSOT doc in the folder the AI instruction protocol's category-to-folder table names. Chief decides the folder for domains 03, 05, 06 and 08. The writer therefore parks those candidates in Chief's queue (IF catalog call 9, ruled 2026-10-05). An `#auth-candidate` goes to `_AUTHORITATIVE/`.
4. Add a version-history row naming the date and the ruling.
