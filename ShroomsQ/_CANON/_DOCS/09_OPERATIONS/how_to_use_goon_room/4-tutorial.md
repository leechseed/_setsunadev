# Your first Goon Room session

You will run one session on the source's own example topic, Mars aspects research. You finish with a tagged file ready for the weekly review.

## Step 1. Create the file

Create `_GOON_ROOM/sessions/2026-02/2026-02-10_mars_aspects_research.md`. The name follows the date-then-topic format.

## Step 2. Work without structure

Write whatever comes: a question, a half-sentence, a link. Do not tidy. The source says no structure is required.

## Step 3. Tag what matters

Suppose one passage is ready for canon. Add `#canon-ready` beside it. Suppose another passage is only a test. Add `#experiment`.

## Step 4. Review at week's end

Search for `#canon-ready`. Move the tagged passage to `_STAGED/`. You are done: the test passage stays where it is.
