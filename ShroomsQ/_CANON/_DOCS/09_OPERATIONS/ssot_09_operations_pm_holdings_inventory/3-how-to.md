# PM Holdings Inventory: how-to

## Find an existing instrument before building one

1. Name the instrument you need. Pick from a charter, assumption log, decision ledger, task register, portfolio board, gate sheet, document container, or style guide.
2. Open the reference page and find the matching section. The sections are PMBOK material (1), Marine doctrine (2), answer-first (3), templates and gates (4), or the Ultrasin registry (5).
3. Read the "Reuse" column for the row.
4. Open the path.

## Judge whether a holding is safe to reuse

1. Read the row's state.
2. Reuse "finished" and "finished distill" rows.
3. Treat "stub" rows as a pointer only.
4. Do not reuse "damaged" rows. Use the named archive copy.
5. Audit any row marked UNVERIFIED before citing it. The Dec-2025 Marine doctrine summaries are the example.

## Find the closest thing to a charter template

1. Open `files/2026-03-19_bvipds-project-chartermd.md` in the archive.
2. Use its deliverable-gated milestones (M-001 to M-007). They key gates to artifacts, not dates.

## Find the standard flow

1. Read the "Cheapest path" section.
2. Open the Project Flow it points to.

## Start the next Ultrasin entry question

1. Open `_CLAUDE_ARCHIVE_2026-08-15/conversations/2026-06-06_buying-and-reselling-unpublished-content-rights.md`, as the addendum directs.
2. Start from its funnel-only assessment. Do not re-derive it.

## Record a new holding

1. Pick the section where the holding belongs.
2. Add a row: path, what it is, state, reuse for the standard flow.
3. Verify the path before you list it.
