# Development Standard: how-to

## Run one increment

1. Write the tasking into BOLO.md the same turn Chief speaks it.
2. Read the sit rep or DOPE SHEET N before deciding anything.
3. If Chief spoke boresight, give the readback, the read, and the clarifying questions, in that order. Wait for Chief to clear delivery.
4. Reply "Good copy" with a one-to-two-line readback, then execute.
5. Build in the formation: gear 1 default, specialists on disjoint inputs, one script reviewer at the fan-in.
6. Deliver the reply, then push the increment onto the sheet as FRAGO N.
7. Close with Oscar Mike: cache note, STATE update, journal, OUT block. Write nothing after the OUT block.
8. Resume a legacy card with Charlie Mike or RTB. Resume a new BOLO from its DOPE SHEET.

## Cancel an order

1. Say "abort abort abort."
2. Keep the abort line in the record. Strike the order.

## Take a detour mid-stage

1. Say "break-break." The loop parks the current stage where it stands.
2. Run the detour.
3. Say "buttonhook back." The loop returns and restates where it was.

## End a stall

1. Name the hold. Write a decider and a conversion date on it. Never leave either blank.
2. Get the ruling from the decider. Do not add structure.
3. Run any default as provisional, with the word and a date.

## Pick the loop's size

1. For a one-turn ask (S), run how copy, build, reply. Skip the sheet.
2. For a BOLO (M), build the DOPE SHEET once and push a FRAGO per increment.
3. For a project (L), use the project flow's brief and gates, and run this loop inside every session.

## Check a rule was followed

1. Find the rule in the audit hooks table.
2. Look for its evidence in the place the table names. The places are the transcript, BOLO.md, the sheet's Log, STATE.md, or git log.
