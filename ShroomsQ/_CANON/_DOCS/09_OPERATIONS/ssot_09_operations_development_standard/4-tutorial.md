# Run the loop once: the 9/15 sit rep

You will follow the source's first example, the 9/15 sit rep run as the formation. You finish knowing where each stage and rule appears in a real run.

## Step 1. Confirm the order

Chief asks for the board. Before any build, the order is confirmed. Rule 1 says nothing builds until how copy clears.

## Step 2. Orient

The board is the orient stage: the sit rep delivers the current state in fixed blocks.

## Step 3. Build in the formation

Three specialists read disjoint sources. They do not talk to each other. This follows the hub-and-spoke build: gear 1, specialists on disjoint inputs.

## Step 4. Run the one reviewer

One script reviewer runs at the fan-in. Its first pass stops on three findings. Rule 5 says one reviewer, never peer checks.

## Step 5. Fix by owner

Each specialist fixes its own finding. No specialist checks another's work. The main line strips one stray key by hand.

## Step 6. Clear and deliver

The third pass clears. The board republishes to its standing page. That is the delivery and the record: the increment lands on the page, not only in chat.

## Step 7. Check yourself

Look at the audit hooks table. Row 5 asks for one reviewer's checklist output and no second specialist re-checking. The run above meets it.
