# The three-check pass: how-to

Source: [📐 ssot_01_three_check_pass.md](../../../_SSOT/01_NARRATIVE_FRAMEWORKS/📐%20ssot_01_three_check_pass.md). Rows are in the [reference](2-reference.md).

## Run a sweep over a roster

1. Pick one check: Fantasy Drive (P8), Sexy Check (P9) or Aesthetic Check (P10).
2. List the roster.
3. Answer that one check for every element, in order.
4. Number each row: F, S or A plus the row number.
5. Finish the sweep before you start the next. Never bundle the three checks per element.

## Write a fantasy line

1. Ask what the audience gets to be, feel or do through the element.
2. Write one line.
3. Number it F plus the row.

## Write a sexy line

1. Ask whether the element is sexy.
2. Write YES or NO.
3. Write one line of why.
4. Mark a NO as correct or acceptable where the element's job is something else, as with the Drop.
5. Mark a YES thin where the element carries only by role.

## Write an aesthetic line

1. Ask which carrier makes the element interesting: COLOR, SHAPE or TEXTURE.
2. Name the main carrier. Name a second in brackets if one applies.
3. Write one line that shows it.
4. If no visual tissue exists, write GAP and flag it. Do not invent one.

## Record a gap

1. Write GAP or thin in the row.
2. Park the missing sheet by name, for example ⏸ Anna sheet (phase 2).
3. Note what the gap blocks. The Anna gap blocks the Tori×Anna collision proof.

## Land a kept line on an entity sheet

1. Wait for Chief to strike or keep the line by number.
2. Find the element's sheet in the landing table.
3. Add the kept line as the `fantasy:`, `sexy:` or `aesthetic:` field. For a plot element or scene, add it to the plot card or scene card.
4. Update the landing table.
5. If the element has no sheet, leave the line in the pass. Then park it as ⏸ OXO element sheets (phase 2).

## Expand the roster

1. Take the next element from the expansion queue. It holds scene cards (the 7 hot rows), the six movements, the Administration, the Diaspora, Bongobabe and the ladder rungs.
2. Run all three sweeps on it.
3. Add its rows to the pass.
4. Number the new element 13 and count up, in expansion-queue order.
5. Keep that one number across all three sweeps: F13, S13, A13.
6. Never renumber a row.
