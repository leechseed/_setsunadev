# The medium grammars: how-to

Terms are defined in the [reference](2-reference.md).

## Adapt a story to a new medium

1. Keep the storyform unchanged. It is medium-independent.
2. Find the target medium's row in the contract table.
3. Rebuild the Telling Profile. Re-answer the Ten Questions with that medium's machinery.
4. Check T3 order, T4 speed and T10 narratee in the texture-by-medium table.
5. Check each Touchstone against the medium's rules.

## Re-answer focalization and duration for film

1. Treat T2 focalization as shot selection: POV, over-shoulder, insert.
2. Treat T4 duration as editing. Use the cut as ellipsis, montage as summary, the long take as stretch.
3. Move interiority into performance or VO. Never state it free.

## Design a game's story layer

1. Treat mechanics as meaning. Check that the systems do not argue against the story.
2. Read the setting slice as level design. S5 SCAR and S10 UNDERSIDE become strata the player walks.
3. Build quest structure as the ladder, with a player-variable sequence.
4. Write direct address as the tutorial voice. The narratee is the player.
5. Check whether any mechanic breaches a Touchstone.

## Build a TTRPG book from a slice

1. Take the setting slice.
2. Print it as a sourcebook or gazetteer.
3. Write the rules as Touchstones made mechanical.
4. Leave the storyform emergent. The table authors it.

## Add a mode to a medium

1. Confirm the work needs a mode, such as animation or documentary.
2. Find the medium's row in the MODE table.
3. Add the mode to that row.
4. Do not add a G-layer to the genre system.

## Extend a v1 scaffold (M6, M7, M8)

1. Read the scaffold's current bullets.
2. Run the BOLO 16 pass: find sourced grammar for the medium.
3. Replace each scaffold bullet with the sourced version.
4. Drop the "v1 scaffold" tag from the heading.

Run the BOLO 16 pass one medium at a time:

1. Chief finds each source and attaches it in Zotero. He then says "rescan Zotero".
2. An MS reads the held source and writes sourced grammar for one scaffold medium (M6, M7 or M8).
3. The author replaces the scaffold bullets and cites the source.
4. The author drops the "v1 scaffold" tag.
5. A medium with no held source keeps its scaffold.
6. ORANGE rows carry craft grammar only.

## Keep ORANGE rows inside the firewall

1. Write only craft grammar in this public doc.
2. Put content systems Ultrasin-side: §B, the shoot set, the taxonomy engine.
3. Mark the row ORANGE.
