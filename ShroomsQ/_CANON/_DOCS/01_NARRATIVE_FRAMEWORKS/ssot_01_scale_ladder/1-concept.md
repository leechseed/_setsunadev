# The scale ladder: containers hold, threads change

## The spine says what a story is, the ladder says what size it comes in

The spine defines a story. The ladder answers a different question: what size things come in and how they nest. It runs from scene to sequence to arc to story to stories within one large series. Each unit gets a definition, a completion test, a governing system and holdings.

## Containers hold and threads change

This is the ladder's core move. Rungs are containers: units of presentation with boundaries. Arcs are not rungs. Arcs are threads: tracked lines of change that run through containers at any span. TV vocabulary blurs this when it calls a run of episodes a story arc. The Command keeps the line clean. Containers hold. Threads change. The ruling is provisional, awaiting Chief.

## A unit is whole when it passes its test

Every rung carries a completion test. A scene must turn a value and carry five commandments. A sequence must answer its question. A story must close every throughline. The tests make "whole" checkable instead of felt.

## The five commandments repeat at every scale

Coyne's fractal idea carries the ladder. The five commandments recur at scene, sequence, act and global scale. One pattern then checks all four rungs.

## A series nests stories four ways

The ladder answers how many stories live in one series. It names four patterns: anthology, serialized, episodic-with-mythology and braided. OXO is serialized, with nested forms architecturally ready.

## A universe never completes

The top rung has no completion test. A universe stays consistent instead. The test there is canon integrity. The `_CANON_NODES/` folder and the SSOT system are that rung's implementation.

## Touchstones forbid, threads change

Touchstones are neither containers nor threads. A thread changes. A Touchstone forbids. So every rung's completion test carries one last clause: and no in-scope Touchstone is breached. A scene that turns beautifully and breaks a Touchstone is a breach, not a whole scene.

## The long read

Addresses make the ladder usable. Every unit gets an address like `OXO.primary.M2.q3.s12.b4`, and every thread gets a span. The spine's tree addresses locate concepts. Ladder addresses locate instances. A library source keys to the first kind, and a manuscript unit keys to the second. The [collision engine](../ssot_01_collision_engine/1-concept.md) keys every output to these addresses. The notation is provisional until Chief rules it.
