# The scale ladder: how-to

Terms are defined in the [reference](2-reference.md).

## Test whether a scene is whole

1. Check for a value turn. Look for at least one polarity flip, + to − or − to +.
2. If nothing flips, call it exposition and stop.
3. Check the five commandments: inciting incident, complication, crisis, climax, resolution.
4. Check that no in-scope Touchstone is breached.

## Test whether a sequence is whole

1. Find the sequence-level question at the head.
2. Find its answer at the tail.
3. Look for a worse question that replaces it.
4. Check the Touchstone clause.

## Test whether a movement is whole

1. Check that all four throughlines advanced one signpost.
2. Find the driver, an action or a decision, that turned the story.
3. Check the Touchstone clause.

## Test whether a story is whole

1. Check that all four throughlines are complete.
2. Check that Outcome and Judgment are delivered.
3. Check that the argument closed from every seat.

## Nest a storyform inside another

1. Give the nested form its own `storyform_id`.
2. Assign each character's role in the nested form. It may differ from the parent role.
3. Run the R5 test on the nested form.
4. Check consistency with the parent. The parent has authority on conflict.

## Choose a series pattern for an IP

1. Ask whether the storyforms are independent. If yes, use anthology.
2. Ask whether one storyform stretches across installments. If yes, use serialized.
3. Ask whether episode forms sit under a series form. If yes, use episodic-with-mythology.
4. Ask whether parallel forms share one OS. If yes, use braided.
5. Close the parent form last, if one exists.

## Address a unit or thread

1. Start with the IP and form: `OXO.primary`.
2. Add movement, sequence, scene and beat as needed: `.M2.q3.s12.b4`.
3. Truncate to the depth you need.
4. For a thread, write its span: `tori.arc[OXO.primary.M1–M6]`.
5. Key manuscript units to ladder addresses and library sources to tree addresses.

## Scope a Touchstone

1. Decide which rung the Touchstone governs.
2. Write its scope as a ladder address span.
3. Check the census table for the matching rung.

## Track a thread

1. Name the thread type: character arc, setting arc, relationship arc, thematic motif or trope instance.
2. Write its span.
3. Do not call it a container.
