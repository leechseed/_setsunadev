# The texture system: how-to

Source: [📐 ssot_01_texture_system.md](../../../_SSOT/01_NARRATIVE_FRAMEWORKS/📐%20ssot_01_texture_system.md). Fields and values are in the [reference](2-reference.md).

## Record a twelve-field TELLING PROFILE

1. Write `scope:` with the ladder address, usually R5.
2. Fill T1 to T10 as in the [layer how-to](../ssot_01_texture_layer/3-how-to.md).
3. In T2, record `perceptual_scope` (whose view) and `informational_denial` (what the reader is denied).
4. In T6, record the distance policy: cinematic, light or deep.
5. In T7, add mood-curve entries, each as emotion · technique · payoff owed.
6. Fill T11 with the channel (M1 to M10) and any grammar overrides.
7. Fill T12 with the story point the telling discharges and the `storyform_id`.
8. Add the `gap:` line: `t1_t2_gap: none` or `flagged (note)`.

## Write a scene card's telling line

1. Open the scene card.
2. Write the line in this shape: voice/level + focal character, speed, register, `t1_t2_gap`.
3. Choose the register from Kempton's seven genre registers where one fits.
4. Leave the profile alone. The line overrides it for this scene only.

## Flag a T1/T2 gap

1. Read the passage once for who speaks (T1).
2. Read it again for whose view the reader gets (T2).
3. Compare the two readings.
4. Set `t1_t2_gap: none` if they match.
5. Set `t1_t2_gap: flagged (note)` if they differ, and write the note.

## Mark a viewpoint silence or a memory

1. Open the passage's T2 entry.
2. Set `focalization_mode` to `silence` where a focalized character deliberately does not report her own thought.
3. Set it to `memory` where the passage is retrospective and sense-based.

## Run the pause test

1. Find a scene marked Pause in T4.
2. Check delimitation.
3. Check motivation.
4. Check rhetorical binding.
5. Take the test's definitions from Bal (BVX.0596). The source names the three checks and does not define them.

## Measure distance with barrier words

1. Take one passage.
2. Count the barrier words.
3. Divide by the passage length and scale to 100 words.
4. Read the band: cinematic, light or deep.
5. On the first trial passage, set the cut points from your result. The source says the first trial calibrates them.

## Add a mood-curve entry

1. Name the emotion: interest, curiosity, anticipation, suspense or surprise.
2. Name the technique that produces it.
3. Name the payoff owed.
4. Write the line as emotion · technique · payoff owed.
5. Add the payoff to the payoff ledger.
6. Close the ledger entry when the story pays it.

## Audit a line of dialogue

1. Remove the line.
2. Ask what the scene loses, using Kempton's seven functions.
3. Keep the line if it carries a function.

This is a revision check, not a schema field.

## Bind the telling to the argument

1. Find the storyform for the work.
2. Write its `storyform_id` in T12.
3. Write the `story_point` the telling discharges.
4. If T12 stays empty, treat the telling as style only.

## Propose a medium's re-instrumenting

1. Pick the channel, M1 to M10.
2. Write it in T11 with its grammar overrides.
3. Re-read T1, T2 and T6 under that channel's grammar. The storyform survives adaptation. The profile does not.

> **OPEN:** the source gives no calibrated barrier-word cut points. The first trial passage sets them.
