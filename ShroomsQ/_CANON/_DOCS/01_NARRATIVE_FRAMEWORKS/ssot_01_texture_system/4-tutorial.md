# Tutorial: fill a profile from the OXO proposal

You will walk The Outliers' proposed Telling Profile, layer by layer. Every value is a proposal. Chief has not ruled it. The source says so: ⏸ OXO telling profile (phase 2). Keep the [reference](2-reference.md) open.

## Step 1: open the profile

Write the scope line:

```
scope:         OXO.primary
```

## Step 2: set voice and vision apart

T1 is heterodiegetic, subsequent narration, with a reliable narrator. A reliability gap is reserved for the Administration's documents.

T2 is internal fixed on Tori by default. It varies per movement by design.

Check: voice and vision are two separate lines.

## Step 3: set order, speed and frequency

T3: told order matches happened order. A licensed analepsis at each movement threshold recovers the buried name, Skeeter Creek.

T4: scene gait by default, with stretch reserved for the crash.

T5: iterative for the Star-Rating's ritual life and the Sync mechanics. Repetitive is reserved for the rename lattice.

## Step 4: set the words and the feeling

T6: deep distance, free indirect discourse yes, Southern Gothic register.

T7: the tone tracks the six-movement descent. Write one mood-curve entry to practice: curiosity, a technique, the payoff owed. The source gives no technique name for OXO.

> **OPEN:** the source names the emotions for each movement but gives no technique or payoff text for an OXO mood-curve entry.

## Step 5: set thresholds, frames and narratee

T8: in-world documents, the Star-Rating and Administration memos.

T9: metalepsis withheld by default.

T10: the implied reader stands where Tori's meritocratic belief has not yet broken.

## Step 6: set medium and function

T11: M1 prose with an M3 serial grammar.

T12: the MC throughline, `storyform_id: oxo_primary_v1`, discharging DCUS's S12 record.

## Step 7: finish with the gap line

Add `t1_t2_gap: none`. Check it against Step 2: the narrator sees through Tori and speaks from outside, and the two readings agree.
