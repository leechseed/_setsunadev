# Tutorial: configure a telling

You will translate three workshop terms into configurations. Then you will start a Telling Profile. Keep the [reference](2-reference.md) open.

## Step 1: separate voice from vision

Take "third limited." Ask T1 first: does the narrator stand inside the story? No. Write **heterodiegetic**.

Ask T2: whose eyes does the reader get? One character's, fixed. Write **internal fixed**.

Check: you wrote two answers, not one. Third limited is heterodiegetic plus internal fixed.

## Step 2: translate two more terms

Try "first person." The narrator is inside the story, so T1 is homodiegetic. The view is one character's, so T2 is internal fixed.

Try "head-hopping." T1 is heterodiegetic. T2 is internal variable, unmanaged.

Check against the grid. All three should match.

## Step 3: begin a profile for The Outliers (OXO)

Write the first line:

```
scope:        OXO.primary
```

The texture system holds a proposed T1 for OXO: heterodiegetic, subsequent narration. The [texture system](../ssot_01_texture_system/4-tutorial.md) gives these values as proposals only. Chief has not ruled them.

## Step 4: stop at the gap

The house finding says OXO has no ruled Telling Profile. No prose exists. So you stop after `scope`. You have a decision menu, not a ruling.

> **OPEN:** the texture layer gives no ruled OXO values for T1 to T10. Only the texture system holds proposals.

## What you did

You split voice from vision and used the grid to translate three terms. You also met the rule that a profile waits for ruling. Next, read the [how-to](3-how-to.md) for the full profile steps.
