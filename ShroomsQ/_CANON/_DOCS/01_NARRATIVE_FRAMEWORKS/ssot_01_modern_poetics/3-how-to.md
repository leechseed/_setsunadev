# Modern poetics: how-to

Terms are defined in the [reference](2-reference.md).

## Run the fantasy check on an element

1. Pick one element: a character, place, object, scene or mechanic.
2. Say its intended fantasy in one breath. State what the audience gets to be, feel or do.
3. If you cannot say it in one breath, mark the element not done.
4. Do not build a taxonomy, framework, meta-layer or rubric around the answer.
5. Write the line in the element's `fantasy:` field. A plot element or scene uses its plot card or scene card.

## Capture a fantasy line

1. Chief speaks the line in-chat. Dictation stays as spoken.
2. If Claude drafts a candidate, mark it `draft`.
3. Promote a draft to canon only when Chief keeps it or speaks it over.

## Run the sexy check on an element

1. Ask: is this sexy? Answer yes or no first.
2. Write one line of why, or why a no is acceptable.
3. Check the answer against P3 saturation.

## Run the aesthetic check on an element

1. Test the element for COLOR.
2. If it fails, test SHAPE, then TEXTURE.
3. Name the one that carries it.

## Sweep the canon with the three checks

1. Run the fantasy check across everything.
2. Run the sexy check across everything.
3. Run the aesthetic check across everything.
4. Never bundle the three checks per element.

> **OPEN:** the application pass over Tori, DCUS, the Drop, storyform and scene cards is BOLO 21 and fires only on Chief's go.

## Test a story against Entertainment-First

1. Check engagement before message, emotional logic over realism, and momentum.
2. Scan the forbid-list: realism fetishism, didacticism, fear-based writing, tokenism, subversion fatigue.
3. Remember the composition: the argument is the cargo and entertainment is the delivery.

## Design a setpiece

1. Pick one of the eight archetypes.
2. Build the anatomy: Setup, Rising Tension, Payoff, Aftermath.
3. Place it at an act break.
4. Follow it with a reset.
5. Check the forbid-list: spectacle without substance, saturated peaks, empty payload, player disempowerment.

## Close a container with a hook

1. Pick one of the five hook types: Mystery, Consequence, Thematic Echo, Character, Mechanical.
2. Interlock or leapfrog it across installments.
3. Plan the payoff. Never only tease.
4. Write a hook-ledger entry in 08 §9A: hook type, the container it closes and the payoff address.
5. Vary the intensity.

## Build a narrative dilemma

1. Write mutually exclusive options.
2. Put real stakes on every path.
3. Give inaction double fallout.
4. Check that the choice advances plot and exposes character.
5. Reject painless exits and stasis-as-option.
