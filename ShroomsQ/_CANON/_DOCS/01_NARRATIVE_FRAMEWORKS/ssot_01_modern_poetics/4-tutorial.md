# Tutorial: run the three checks on one element

You will run the three checks the way the doctrine orders. The doc holds no worked element, so you pick your own from your current work. Keep the [reference](2-reference.md) open.

> **OPEN:** the source gives no sample answers for P8 to P10. Chief's own spoken lines are the canon form.

## Step 1: pick one element

Choose a single thing: one object, one place or one scene. Write its name on a line.

## Step 2: run the fantasy drive (P8)

Say aloud what the audience gets to be, feel or do through this element. Use one breath. If you run out of breath, the fantasy is not clear. Mark the element not done and stop here.

## Step 3: capture it

Write the line as you said it. Do not polish it. If someone else drafted it, mark it `draft`. Chief's spoken line is the canon form.

## Step 4: run the sexy check (P9)

Ask: is this sexy? Write yes or no. Then write one line of why. If the answer is no, write why that is acceptable.

## Step 5: run the aesthetic check (P10)

Ask whether the element is interesting in color. If not, ask about shape. If not, ask about texture. Write the one that carries it.

## Step 6: stop at one breath

Look at your three answers. Each should be one line. If any grew a taxonomy, a framework or a score, delete the extra.

## Check yourself

You did it right if you used three short answers and no scaffolding. The doctrine forbids multiplying the articulation upon itself. Next time, run each check across all elements before starting the next check.
