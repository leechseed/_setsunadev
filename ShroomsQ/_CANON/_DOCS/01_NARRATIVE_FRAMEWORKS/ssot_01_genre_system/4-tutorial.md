# Tutorial: read OXO through the twelve genre layers

You will walk the OXO worked example. Only G1 is ruled. The rest are parked lines that show the method. Keep the [reference](2-reference.md) open.

## Step 1: name the label (G1)

Write the label. OXO's critical label is cultcore, ruled 2026-09-29. Write the industry and marketing labels in separate fields. They read as a prestige-school drama, a YA-adjacent institutional dystopia. Notice that the three labels do not agree.

## Step 2: place the family (G2)

Put OXO in Truby's Coming-of-Age family, individual focus. Its polar opposite is the Gangster/Crime family, society focus.

## Step 3: list the conventions (G3)

Write the weakness-need frame and the apparent-choice-versus-restriction world build. Then add the five cultcore conventions. Mark each as parked until Chief rules.

## Step 4: state the argument (G4)

Write the proposition: merit does not earn freedom, and visibility invites ownership. This is an argument, not a feeling. A feeling would go on the texture mood curve.

## Step 5: set stance and delivery (G5, G6)

For G5, write the generalized fantastic: the abnormal is the norm from page one. For G6, write immersive. Characters are natives, not visitors. Sync is used and never explained.

## Step 6: set regime, world, uptake (G7, G8, G9)

Write the two verisimilitudes: the American prestige school and the institutional dystopia. Write the world: the Southern Gothic register and the DCUS slice. Write the series form: six movements.

## Step 7: set audience and market (G10, G11)

Write the stacked ICM, with the Vicarious V dominant. Write the market as a mid-budget serial. Where the distills say nothing, write unknown.

## Step 8: bind to the storyform (G12)

Write `storyform_id: oxo_primary_v1`. Now the genre entry is the argument's contract. It is no longer a shelf label.
