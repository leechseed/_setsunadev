## VIGNETTES (a kind of story, not a story row)

Ruled 2026-10-01 (BOLO 96, Chief: "all rec"). A vignette is a short told piece with no full arc. It sits beside the stories, never counted as one, and carries no storyform.

- **Wiring:** each vignette tags the worldbuilding catalog entries it shows (`WB-<TYPE>-<nnnn>`, ssot_05_worldbuilding_system).
- **Canon status:** lineage by default (the Ariel rule, where Ariel is Tori's earlier name). It may float ideas without locking canon. Chief rules it in, and only then it reads as canon.
- **Tags:** era required (1 Skeeter Creek, 2 DCUS, 3 LAKAD, 4 ASTRO7EX, 5 beyond). Time code optional (`M2 · Q1 · S03 | bar.beat.tick`, ssot_08_tracking_system).
- **Intake:** spoken by Chief (10/1). The text lands in `_CANON_NODES/vignette-<slug>.md`, near-verbatim. The row lands here.
- **ID format:** `VG-<nnnn>` (version history, 0.1.9).

Table columns: ID, Title, Era, Shows (catalog), Time code, Status, Gist, Node. The table holds no rows yet.

## THE ROW

A new story fills these fields.

| Field | Rule |
|---|---|
| `id` | Short, lowercase. Used by tracking files and the `stories:` filter |
| name | The story's name |
| aliases | Other names |
| genre | The G1 slot (ruled 2026-09-29, BOLO 91). Blank `—` until named |
| era | One of the five eras |
| where | Place |
| medium | Medium |
| status | Named only, then reports in, then storyform drafted, then active. Provisional (seed) for a story sourced from a digest and not yet ruled |
| storyform | A link |
| nodes | Canon nodes |
| data | Its tracking file, once one exists |

**Blank slots (ruled 2026-10-04).** An unnamed slot reads `—`. A slot Chief deferred to a pass reads `⏸ <pass name> (phase 2)`. Neither mark counts as unfinished work.
