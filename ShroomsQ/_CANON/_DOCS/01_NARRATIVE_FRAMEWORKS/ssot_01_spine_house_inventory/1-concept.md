# The spine house inventory: the repo's own shelves

## The Command already owns a library

The spine needs sources at every level. The Command did not start empty. The repo holds processed materials of its own: canon nodes, protocols, bibles, templates and reference works. The inventory keys each one to a spine level, L0 through L7. The repo's own holdings become the spine's first shelves.

## Level order makes the map readable

The inventory runs by level. A file that serves several levels appears at its home level and lists the others in an "also" column. A reader looks up a level and sees what the Command already holds there.

## A sweep is a measurement

The sweep was stage 1 of BOLO 18, an agent pass on 2026-08-26. It measured as well as listed. It found a numbering collision, a distill gap and machine-readable storyform exports. It found a complete worked method on the INSPIRATION shelf and prior art for the TV Tropes work. It also found duplicate files. Stage 2 keys the external library the same way.

## The first count was wrong

The sweep scored the craft shelf at 0.6% distilled, two of 353 sources. That missed 109 finished framework distills in the archived `X_`-prefixed build lineage. The 2026-09-03 addendum corrects it. The Command promoted those distills to the narratology shelf. A finding stays in the record, and the record carries its own correction.

## Some files sit outside the map on purpose

The keying infrastructure is unmapped by design. It is the instrument that does the keying. It includes the one-sheet template, the spec, the taxonomy, the library state reports and the repo's self-account. A map does not list its own tools.

## The long read

The inventory marks cross-level payload because the spine is a tree. A single file such as the texture layer serves L0, L4 and L7 at once. The inventory also names what the Command lacks. The Movement-to-Signpost table, the pre-reserved empty folders and the thin Quinn Bishop file all show where the house stopped short. The domain numbering collision was ruled 2026-09-16: plot is `04_PLOT_SYSTEMS/` and style guides are `06_`.

For the level-by-level holdings, see the [reference](2-reference.md).
