# Character astrology: tutorial

You will classify a datum, give two planets an aspect, and test one planet for dignity. Every example comes from the source. Reference tables are in the [reference](2-reference.md).

> **OPEN:** the source holds no complete worked chart with signs. This lesson uses the examples it does hold: Equity and Inequity as Problem and Solution, and Mars for a Proaction-driven character. Sign choices stay with the DAI doc.

## Step 1. Sort two items

Take these two items. Decide for each whether it is character-level or story-level.

- A planet that stores the character's deleted memories (the 12th House).
- A transit where Saturn Return forces an audit at a story milestone.

Check yourself with the test: does it say who the character IS, or what is HAPPENING to them?

The 12th House planet is character-level. It sits in the static chart. The Saturn Return is story-level. It is a state diff and never edits the natal chart.

## Step 2. Give two planets an aspect

Suppose a character's Dramatica data holds Equity and Inequity as Problem and Solution.

1. Find the planets behind each. The Moon takes the MC Problem and MC Response. Uranus takes the MC Solution.
2. Ask whether the two elements are in natural tension. Problem and Solution are.
3. Choose a hard aspect: Square or Opposition.
4. Name the gate. An Opposition is an XOR gate. The character cannot run both variables at once.

You now have the shape of one aspect line: two planets, one aspect, one Dramatica source, one gate. The ingest template records exactly that.

## Step 3. Test one planet for dignity

Take Mars for a Proaction-driven character.

1. Name the planet's Dramatica element. Mars derives from Approach and the Motivation quad.
2. Compare it with the sign's natural mode. The source example puts Mars in a cardinal fire sign.
3. The element and the mode align, so Mars receives Essential Dignity.
4. Move Mars to a cardinal water sign. The two now conflict, so Mars receives Essential Debility.
5. Write the texture in one sentence. A debilitated Mars acts at internal cost, with emotional volatility or structural inefficiency.

That texture goes to L10 SHADOW and L5 WOUND. The character can still act. The chart records how it costs them.

## Step 4. Check yourself against the policy

Ask three questions about your work.

1. Did every placement trace to a locked Dramatica position?
2. If astrology suggested something Dramatica contradicts, did you revise the chart?
3. Did you leave a story-level datum out of the natal chart?

If all three answers are yes, you have followed the narrative-first policy.
