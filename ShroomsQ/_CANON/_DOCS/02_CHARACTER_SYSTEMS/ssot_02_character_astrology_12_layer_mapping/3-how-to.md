# Character Astrology to 12-Layer mapping: how-to

Feed lists live in the [reference](2-reference.md).

## Justify a layer value from the chart

1. Find the layer's row in the Master Feed Table.
2. Read its chart sources in your Character Astrology Ingest Template.
3. Read the layer's feed specification for what each source implies.
4. Write one line of justification prose in the Vertical Slice for the layer.
5. Run the layer's consistency check. Add a documented explanation if the value and chart disagree.

## Set the WILL buy-up or buy-down

1. Start from WILL = CORE.
2. Read the Saturn sign and dignity.
3. Saturn in dignity: keep WILL >= CORE.
4. Saturn in debility: choose WILL < CORE, or WILL > CORE with a fragility note.
5. Read the Sun-Saturn aspect for rigid, tested, stable or swinging resolve.
6. Buy at 5 pts per level.

## Decide ambition-driven or meaning-driven (L6)

1. Start from DRIVE = VITAL.
2. Read Mars dignity.
3. Read Jupiter's sign against Mars's element.
4. Mars in dignity with a compatible Jupiter: choose ambition-driven (DRIVE = VITAL).
5. Mars compromised, or Jupiter in tension: choose meaning-driven (DRIVE < VITAL).

## Estimate shadow density (L10)

1. Count the debilitated planets.
2. Count the planets in the 12th House.
3. Count the hard Pluto aspects to Sun, Moon, Mercury, Venus and Mars.
4. Add the counts. 0-1 gives shadow_density 1-3. 2-3 gives 4-6. 4+ gives 7-10.
5. Adjust to the documented psychology. The estimate is not a formula.

## Lean an attachment style from the Moon (L8)

1. Read the Moon's element.
2. Take the lean: Water toward anxiety, Earth or Air toward avoidance.
3. Read the Moon's aspects and adjust the lean.
4. Read the Moon's dignity for imprint_flexibility.
5. Set the fields with no feed from the authoritative document.

## Add the schema-pass fields

1. Look up the field in the Schema-Pass Fields table.
2. If it reads "no feed", set it from the authoritative document alone.
3. If it reads "texture only" or "check only", use the named chart feed to check or color it.
4. Never let the chart set the field.

## Map a Tier 2 chart

1. Feed the Sun to L1 CORE.
2. Feed the Moon to L8 IMPRINT.
3. Treat every other layer as "no feed".
4. Run only the L1 and L8 lines of the checklist.

## Resolve a chart and layer conflict

1. State exactly which chart element contradicts which layer value.
2. Check the locked authoritative document.
3. If it supports the chart, change the layer value. If it supports the layer value, change the chart.
4. If the document is ambiguous, keep the layer value and change the chart.
5. Record the resolution in the astrology ingest (Section 9 notes) and in the Vertical Slice layer prose.
6. If the document contradicts itself, stop. Flag it for narrative designer review and revise the document first.

## Run the Feed Validation Checklist

1. Confirm the Character Astrology Ingest Template and the Vertical Slice are both complete.
2. Walk the 15 items in order.
3. Mark each item pass or carry a documented exception.
4. Resolve every open conflict by the Conflict Resolution Protocol.
5. If the chart is only minimum-viable, wait. The checklist cannot run until the full chart is locked.
