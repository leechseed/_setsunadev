# L9 EROS synthesis: how-to

Lookups: [reference](2-reference.md). Why: [concept](1-concept.md). The current field definitions are in the [vertical slice](../ssot_02_character_systems_vertical_slice/2-reference.md).

The source states the method in its Method section. Chief orders each pass and rules each change.

## Trace an L9 field back to its sources

1. Find the field in section 5 of the synthesis, "PROPOSED CHANGES to L9".
2. Read the change's "Cites" line. These are the distills that argued for it.
3. Open section 2, the per-distill register. Find each cited ID.
4. Read the "Field fed / gap exposed" column to see what each source said.
5. Read section 3 to see whether the field rests on a pattern that two or more sources share.
6. Read the vertical slice for the field's current definition.

## Find which sources inform a given L9 topic

1. Open section 3, "Recurring methods across the shelf".
2. Find the method that matches the topic, such as signal literacy or disclosure.
3. Read the list of sources named for that method.
4. Look each up in section 2.

## Run a new synthesis pass on a new shelf

1. Collect the new distills. Give each an ID in the shelf's series.
2. Read the whole shelf against L9's current fields, not one source at a time.
3. Build a per-distill register: ID, title, what it says L9 should hold, field fed or gap exposed.
4. List patterns that at least two distills reach independently.
5. Survey the trope side. Group the tropes keyed to L9 into clusters.
6. Write at most ten PROPOSED CHANGES. Give each a concrete rule change, its cites and a one-line rec.
7. Treat queer and male-male desire as first-class material. Build a mechanism once, gender-neutral. Do not add it as an exception.
8. List open questions. Do not decide them. Chief decides.
9. Mark every change provisional until Chief rules.

## Decide whether a change is a field or a craft rule

1. Ask whether the idea describes something true of a character.
2. If it does, it is a field. Add it to the layer and tag it.
3. If it describes how prose narrates a scene, it is a craft rule.
4. Write a craft rule as a Core Methodology subsection. The pacing toolkit is the model: no new field.

## Split one field into two without breaking old records

1. Name the new fields. The synthesis split `shame_index` into `exposure_shame` and `role_shame`.
2. Keep the old field as a read alias for one of the new ones. `shame_index` reads as `exposure_shame`.
3. Backfill the new field from text already on record, as Victoria's `exposure_shame` was.
4. Mark the new field you cannot backfill as null with the ⏸ marker. Invent no canon.

## Resolve an open question

1. Pick the question from section 6.
2. Gather the sources and the layers involved.
3. Write a recommendation in one line.
4. Present it to Chief as a numbered question with the rec. Chief rules.
5. Record the ruling with its date, as the WLW gap ruling was recorded: RULED 2026-09-29, logged to the acquisition list.
6. Apply the ruling in the vertical slice at the next schema bump, and bump the version.
