# Prose style: how-to

Terms are defined in the [reference](2-reference.md).

## Check a draft against the guide

1. Open the IP's Telling Profile. If T1 is not ruled, stop. The draft has not cleared the guide.
2. Read the draft once. Mark each scene's focal character and record it as the scene card's `focal:` field.
3. Run the ten questions of "The check" in order. Answer yes or no for each.
4. For each no, note the section the question cites.
5. Where the Telling Profile rules the question differently, the profile wins. Drop the finding.
6. Return the remaining findings to the writer.

## Rule a new IP's Telling Profile lines

1. Open the IP's Telling Profile. Find the T1 line.
2. Record person, level, reliability and time of narration.
3. Start from the recommended menu item: past tense, single internal-fixed focalization. Strike or keep it per the IP's storyform.
4. Record the T2 line. Name any licensed second lens.
5. Record the T6 line: registers, dialogue registers, and the distance setting.
6. Record the T4 line, including where stretch is licensed.
7. Check that no line contradicts a universal rule: motive, description, paratext.

## Check a scene's motive handling

1. Read the narration, not the dialogue.
2. Find any line where the narrator says why a character acts.
3. Mark each such line as failing the guide.
4. Rewrite so the page shows the character's action, speech or refusal.
5. Leave the wound and drive on the character sheet. Do not state them in narration.

## Check a description

1. Find the detail.
2. Ask what it points at: theme, distinctiveness, or a named motif.
3. If it points at nothing, cut it.
4. If the scene pauses to describe, run Bal's three tests: delimitation, motivation, rhetorical binding.
5. Ask if the description could belong to any scene. If yes, replace it with one only this story's theme could produce.

## Check a line of dialogue

1. Pick the line.
2. Name which of Kempton's seven functions it discharges.
3. If it discharges none, cut it.
4. Confirm the line fits its canon-keyed register on the IP's T6 line.

## Check a draft's pace

1. Open the IP's planned tempo curve in the tracking system.
2. Check that every beat opens with a `<!-- beat: M2 · Q1 · S04 | 012.3 -->` mark. Count the marks per scene and measure the audience tempo in beats per 1,000 words.
3. Compare the measured curve to the planned one, scene by scene.
4. Mark where the draft drags or rushes against plan.
5. Do not compare against a universal number. None exists.

## Add the disclaimer to a book

1. Open the book's front matter.
2. Paste this line exactly, unchanged:

```
Fantasy, not a how-to: what happens in these pages stays in them. Reader discretion advised.
```

3. Add nothing else to the front matter for this purpose. The disclaimer is one line.
4. Judge the scenes separately, by P3 SATURATION. The disclaimer does not excuse or replace that judgment.
