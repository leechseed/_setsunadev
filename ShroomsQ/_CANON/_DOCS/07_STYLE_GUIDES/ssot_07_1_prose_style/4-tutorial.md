# Prose style: run the check on OXO

You will walk the ten questions once. The source's worked instance is OXO's Telling Profile (RULED 2026-09-23). This lesson uses only what the guide says about it. It does not write story.

## Before you start

You need the OXO Telling Profile, `_CANON_NODES/oxo-telling-profile.md`, and a draft page to judge. Keep the [reference](2-reference.md) open.

## Step 1: confirm T1 is ruled

Open the profile and find T1. The guide records OXO's answer: heterodiegetic, subsequent narration, a reliable narrator. The reliability gap is reserved for the Administration's documents.

T1 is ruled. The draft can be judged. If it were blank, you would stop here.

## Step 2: name the focal character

Read the draft. In each scene, ask who sees. OXO's T2 rules Tori fixed by default. The Feed's surveillance eye is the one licensed second lens. It is external and never a character POV. Anna has no POV.

Mark any scene that enters Anna's head. That scene fails question 2.

## Step 3: read for register

OXO rules three dialogue registers. Axiom is declarative with no questions. Noise overlaps and trails off. Truth is few words, all true.

Pick one line from each register in the draft. Check each against its rule. Plain is the default everywhere else.

## Step 4: test one description

Find one description. Ask what it points at. The guide names OXO's motifs: the uniform and the mirror, a door she could walk out of, and the Feed.

If the detail serves one of those, it passes question 5. If it could sit in any scene, cut it.

## Step 5: test one line of dialogue

Name the Kempton function the line discharges. If you can name none, the line fails question 6.

## Step 6: read for motive

Scan the narration for any line that says why a character acts. Each one fails question 10. Rewrite it as an action, a spoken line, or a refusal.

## Step 7: check pace and paratext

Compare the draft's tempo to the planned curve (question 7). Then check the front matter for the one-line disclaimer (question 8). OXO's Ban is a hard cut: a person removed mid-scene and never returned to.

## Step 8: finish

Question 9 applies because OXO's G1 label is cultcore. Does the institution's voice, Axiom, read distinct from the outsider's, Truth?

You have now run all ten questions. Count your noes. Each one names a section to fix. For the same steps on other tasks, see the [how-to](3-how-to.md).
