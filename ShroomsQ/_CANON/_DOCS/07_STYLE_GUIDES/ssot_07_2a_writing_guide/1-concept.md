# SSOT writing guide: why the standard is rigid

## An SSOT stays canonical by being precise

An SSOT is a Single Source of Truth document. The guide sets the standard for all of them. It keeps every framework canonical, precise, and fit for the Obsidian Properties UI.

The guide gets there through rigid language and a rigid frame. A canon document that hedges is not canon.

## Language carries authority

The guide borrows its tone from Marine Corps doctrinal precision. A writer states the method as an active, perpetual reality. That means present tense, active voice, and no hedges such as "basically," "perhaps" or "maybe."

The first instance of a technical term is bold and defined at once. Bold belongs to the writer. A reader who marks a document uses highlight instead, so the two inks never mix.

One older rule fell. The guide once banned contractions. Chief ruled them allowed on 2026-10-04, because text must read clean out loud.

## The frame is fixed, the body is not

Every SSOT document keeps one frame: YAML, a titled H1, a table of contents, a purpose, and a version history. The body in the middle follows the page's type.

The old guide forced every page to carry Core Methodology, Implementation and Examples. That put a concept, a how-to and a reference on one page. The new rule gives each page one type and one body shape.

A reviewer names the page's type first. Then the reviewer checks the body against that type. Without that step the rule has no test.

## Metadata must render

The YAML header feeds Obsidian's Properties panel. Lists use flow style, wikilinks are double-quoted, and each key has a space after its colon. These small rules guarantee the panel renders.

The header also carries the page's keeping fields: reader, doc_type, owner, state and reviewed. Older fields stay until the schema pass.

## The long read

Three of the five 2026-10-04 merge calls reshaped this guide. Contractions are allowed. The frame stays while the body follows type. The header fields are added. A fourth call split a stray Goon Room protocol out of this file into 09_OPERATIONS. So the guide holds one job.
