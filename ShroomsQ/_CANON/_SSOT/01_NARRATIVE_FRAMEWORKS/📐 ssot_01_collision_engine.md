# 📐 SSOT: THE COLLISION ENGINE — slice against slice

**What this is:** the lattice's analysis layer. It takes two (or more) filled schemas — character stack, setting slice — and reads them against each other, producing **friction, which is dramatic material**. The full collision table for a pair is functionally a scene-generation menu.

**Architecture — RULED 2026-08-26:**
- A layer **above** the entity schemas,
- that **feeds back down as overlays** — friction tables → scene-card material; transit hits → state diffs. **Baselines never mutate** (the Cat 11/12/13 immutability rule, inherited verbatim: none of these operations modify the natal record).
- **Time is the substrate:** every output is keyed to a ladder address or span.

## THE FOUR CLASSES

| Class | Machinery | Output record |
|---|---|---|

| **C×Situation** | Cat 13, activated: a situation = a setting state + social configuration **pinging** the static chart. The chart defines which variables are vulnerable; plot_systems (and the scene card) define when pings fire. | State diff on the character, keyed to the firing address. |
| **C×G** — character vs group | Mesh at N members + group composite; the character's L7 ORIGIN and L8 IMPRINT are the receiving surfaces. Dramatica-side check: the group's 64-element distribution (is the Story Mind complete?). | Group mesh + per-member rows. Specced fully at first ensemble need. |

## CONTACT VOCABULARY — how a row classifies *(provisional, astrology-native)*

| Contact | Reads as | Drama value |
|---|---|---|
| **Conjunction** | fusion — the two share the trait; mutual recognition or mutual exposure | high, intimate |
| **Trine** | flow — the place feeds the character effortlessly. **Watch it: a trine from a hostile entity is a seduction.** | high when weaponized |
| **Square** | friction — grinding, chronic conflict | the workhorse scene fuel |
| **Opposition** | confrontation — direct, stakes-explicit | high, climactic |
| **Void** | no contact — the row produces no drama, and that is a legal, informative result |

**The discrimination rule:** a healthy collision table has cold rows. An engine that declares every row hot is astrology-as-flattery, not analysis.

## OUTPUT CONTRACT

- **Collision record:** `{pair, class, scope (ladder address/span), rows[{layers, contact, reading, scene_potential}]}` — stored beside the slices, never inside them.
- **Overlay record** (C×Situation): state diff on the character keyed to the firing address; the scene card's `invariants:`-adjacent line names its source.
- **Scene card wiring:** the card gains a `collision:` line — which row(s) seeded the scene. A scene not seeded by any row should justify itself.
