# The system renumber and the LEECHSEED name

Chief ruled both on 2026-10-05 ("All recs go", BOLO 103). This record is never edited; a later change gets a new record that points back here.

## What we decided

Chief kept systems 00 to 04 and renumbered 05 to 09.

| Old | New | System |
|---|---|---|
| 05 | **09** | Operations |
| 06 | **07** | Style guides (06.1 → 07.1, 06.2 → 07.2, 06.2a → 07.2a, 06.2b → 07.2b, 06.3 → 07.3) |
| 07 | **06** | Theme |
| 08 | 08 | Tracking |
| 09 | **05** | Worldbuilding |

Chief also named the character system **the LEECHSEED character system**. The name replaces "the 12-layer character database" and "the 12-layer character system".

## Why

Chief, 10/5: "world building should not be nine. It should be like five. And operations and tracking should be at the bottom."

The numbers now read in build order. The story systems come first, then what the story argues, then how it reads. The machinery comes last.

Chief chose LEECHSEED as a name he can protect later. "Twelve layers" stays as a description of what the system holds.

## What we gave up

A script rewrote 1,463 references across 178 live files and renamed 30 files and 8 folders. Older notes, logs and cache notes keep the old numbers. Read them through the table above.

TM 02, TM 03 and TM 04 kept their numbers, because systems 00 to 04 did not move.
