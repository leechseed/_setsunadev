# 📐 PATTERN CARD: CHARGE AND SPEND — build the meter, then empty it

**Who it's for:** anyone designing a contest, a character resource or a story's pacing · **What it does:** gives a system one meter with a fill action and an empty action · **Type:** pattern · **Status:** research 0.1.0, not canon

## THE PATTERN

**CHARGE AND SPEND** is a loop with one resource. One kind of action fills it (the **charge**). Another kind empties it for a bigger effect (the **spend**). The player's real choice is *when* to spend, not *which* move to pick. That timing gives the loop a flow: build, release, build again.

Five parts:

- **Meter:** the one resource. It has a **cap** so it cannot be hoarded forever.
- **Charger:** the cheap, safe, repeatable action that fills the meter.
- **Spender:** the strong action that costs meter. It cannot fire on an empty meter.
- **Release timing:** some spends get stronger the longer you hold them (a wind-up).
- **Reset:** after a spend the meter is low, so the next build starts.

Chief, 10/6: "you charge up your [mana] bar and then … you use attacks … then you charge it again … it has a flow to combat … It's also simple but emergent."

## THE SOURCE: AION 2 (web check 11/4)

Aion 2 is an MMO (a massively multiplayer online game) from NCSoft. Its combat mixes tab-targeting with action play, and it has no auto-combat. [1][2]

- **Spend:** most skills cost MP (mana points). A skill cannot be used without enough MP. [3]
- **Charge:** each class has opener skills that restore MP. Examples: the Gladiator's Keen Strike restores 100 MP; the Ranger's Snipe restores 120 MP. [3][4] Guides tell players to weave the basic attack between skills to keep MP topped up. [5][6]
- **Release timing:** charge skills (the Sorcerer's Hellfire, the Cleric's Bolt) hold up to three charge levels. Guides warn that macros release them early. [5][6]
- **Chains:** a skill opens a short window for a follow-up skill. Missing the window resets the chain. [2]

Reading note: "Manus Bar" in the spoken line is read as the MP (mana) bar. Provisional.

## THREE PLACES IT CAN LIVE

1. **The TTRPG layer (BOLO 101).** A contest meter. Safe moves (probe, guard, feint) charge it. Big moves (the finisher, the reveal, the escape) spend it. The GM caps the meter so players must spend.
2. **A LEECHSEED character resource.** One meter per character: pressure, nerve or heat. Scenes charge it. Choices spend it. In EUROPATCH terms the meter is a module: the cap is a dial, charge sources plug into its input jacks, spends leave through its output jack.
3. **The fabula's tension economy.** Quiet beats charge the story. Set pieces spend it. A set piece fired on an empty meter reads flat. A meter left full too long reads as a stall.

## FAILURE MODES

- **No cap:** players hoard and the rhythm dies.
- **Boring charger:** the fill action is a chore, so the loop feels like a grind.
- **Free spend:** the big move costs nothing, so there is no build at all.

## OPEN CALLS (recs given)

1. **One meter or one per role?** Rec: one per character to start. Add more only if play shows a need.
2. **Does the fabula meter get a number?** Rec: no. Track it as low · building · full, beat by beat.
